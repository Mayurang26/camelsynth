# Zebra 2 Web - Modular Synthesizer
A web-based modular analog modeling synthesizer heavily styled and architected after **u-he Zebra 2**.

## Key Features Inspired by Zebra 2:
1. **Addable Modules (Dynamic Patching):**
   - Click **`+ ADD MODULE`** on the left column to dynamically add Oscillators (OSC), Filters (VCF), Noise, or Distortion modules!
   - Every module can be tuned, reconfigured, or deleted using the **`✕`** button on its header.
2. **Iconic Zebra 2 Synthesis Matrix:**
   - The center grid reflects every module you instantiate in real time across four vertical signal lanes with green/burgundy module tags.
   - Includes lane mixer dials and bus controls.
3. **Modulation Rack (Right Column):**
   - Dedicated Envelope 1 (Amp), Envelope 2 (Filter Mod), and LFO pods with analog exponential response curves.
4. **Preset Browser:**
   - Click the preset arrows at the top to load presets like *init Zebra2 Modular*, *Analog Brass & Lead*, or *Dark Ambient Drone*.
5. **Zero Latency & 0ms Load Times:**
   - Zero external font blockers, no freezing loops, and real-time Web Audio API node compilation.
